3. Renew or end access

          

            
            
            
          

          

            Renew keeps the same worker and file. The file selector above cannot
            change this job. Renewal is manual in this starter.
          

          

            Revoke stops the current grant: retry the read to see denial. The
            saved approval still allows renewal. End workflow disables that
            approval, blocks every grant from it, and stops the worker process.
          

          

            Restart with npm start to resume the saved assignment.
            Restart never renews a grant or re-enables an ended workflow.
